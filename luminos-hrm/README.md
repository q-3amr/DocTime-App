# Luminos HRM

A polished ASP.NET Core MVC employee management system for the Luminos HRM brief. It includes a seeded directory, search and department filtering, a four-stage onboarding presentation, attendance KPIs, status updates, and responsive SaaS styling.

## Run

Install the .NET 8 SDK, then run `dotnet run` from this directory. The repository also contains the original DocTime Flutter project under `../doctime`; Luminos HRM is intentionally isolated in this folder.
